# reeficon

Reef encode/decode helpers for icon payloads in pipelines.

**Site:** https://theworker02.github.io/reeficon/

## Install / run

```bash
git clone https://github.com/theworker02/reeficon.git
cd reeficon
node src/cli.js
node --test
```
